## Quality findings and changes made after the run

1. **Quotes that join lines (G2).** The prompt now requires the quote to be one continuous run from a single line of the page. The GalleryToddlers! page now passes (re-checked with the new prompt).
2. **Outing ages defaulting to 0–36.** The prompt now says: use the age the page states; with no stated age, include only places clearly suited to babies or toddlers, with a realistic minimum age; skip thrill rides, waterpark slides, ticket pages, and talks with no young-child angle. The reviewer now scores ≤3 for age ranges the page doesn't support.
   - Re-check: Adventure Cove changed from 0–36 to 12–36 months, still accepted. TRICK or THRILLS still 0–36, accepted. The Mandai ranger talk changed to 12–36.
   - These are judgement calls. Check the staged outings before the first publish.
3. **Outing names** are the organiser's official titles, so they are no longer checked for copied text. The summary still is.
4. **Same-day staged files.** The daily job overwrote the weekly staged file on the same date. Fixed: staged files from different jobs on the same day are now merged. The weekly file was restored from bucket object versioning and now includes both runs.
5. **For your review in `safety_rules.yaml`:**
   - "Halloween sensory bin with beans and pom poms" (18 months) passed both G4 and G5 because its safety note says "supervise". If dried beans and pom-poms should be blocked under 24 or 36 months instead of needing a note, change `sensory-fillers-need-supervision` to a `block` rule with `below_month`.
   - "Salt writing tray" and "Bake a pretend cake" rely on "supervise" notes.
